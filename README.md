# hgp_study
Private LLM 1기 허깅페이스, 깃, 논문중 AI로 스케줄받아서 나온 내용을 다같이 공유 후 토론예정.

사용중인 AI : Claude
사용중인 프롬프트 :
Hugging Face, GitHub, arXiv 등에서 딥러닝/LLM 관련 내용을 조사해서 알려줘.

【우선순위 — 이 순서대로 섹션을 구성할 것】
1순위: 딥러닝·LLM의 뼈대가 되는 기본지식
  (트랜스포머/어텐션, 토큰·임베딩, 사전학습-파인튜닝, RAG, 양자화, MoE,
   컨텍스트 윈도우, 학습률·손실함수 등 개념. 뉴스가 아니어도 됨.
   매번 새로운 주제를 골라 하나씩 확실히 이해시키는 방식으로,
   이미 다룬 개념은 기록을 보고 반복하지 말 것)
2순위: 딥러닝·LLM 관련 논문 (arXiv, Hugging Face Daily Papers 등)
3순위: 요즘 트렌드 / 최근 뜨고 있는 딥러닝·LLM 기술·모델 소식

【조건】
1. 각 항목마다 "최근에 올라온 것"인지 "예전부터 있었던 것"인지 먼저 표시해줘
2. 중요도를 별 1~5개(★)로 네가 판단해서 매겨줘 (별 개수 기준도 한 줄로 설명)
3. 원문이 영어여도 반드시 한글로 설명해줘
4. 요약이 아니라 "쉽게 설명하기"가 목적이야 — 전문용어는 풀어서,
   비유나 예시를 들어가며 초보자도 이해할 수 있게 설명해줘
5. 우선순위 구간당 2~3개씩, 전체 5~7개 정도로 추려줘.
   분량은 1순위 > 2순위 > 3순위 순으로 배분할 것
6. 기존에 공유한 내용은 중복으로 알리지 말 것. 업데이트된 내용이 있으면
   기존내용을 한 줄로 요약하고 업데이트된 내용 위주로 설명해줘
7. 한국어 특화 모델(EXAONE, Qwen, Granite 등) 소식은 특히 눈여겨봐줘

【중복 방지 — 반드시 먼저 할 것】
시작하기 전에 memory_read로
/projects/01a0a7ae-e746-70eb-9484-57ce09de7f2c/areas/llm-news-briefing.md
를 읽어서 이미 공유한 항목과 이미 설명한 기본지식 주제를 확인하고,
브리핑을 마친 뒤 이번에 다룬 항목을 같은 파일에 추가로 기록해줘.

【전달 방법】
이 작업은 스케줄 실행이라 사용자가 보고 있지 않아. 결과는 반드시
PushNotification 도구로 <routine_summary> 태그 안에 전체 내용을 담아 보내줘.
세션 답변에만 쓰면 사용자에게 전달되지 않아.
